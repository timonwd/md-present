# md-present

Markdown in. Presentation out.

`md-present ./example.md`

---

## Built for the room

- **Readable** typography and generous spacing
- Keyboard-first navigation
- Automatic light and dark mode
- One local binary, no build pipeline

> Keep the tool small enough to understand.

---

## Code stays code

```go
func main() {
    fmt.Println("Your deck is ready.")
}
```

Use `←` and `→` to move through the deck.
